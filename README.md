## 隐云(YinYun)VPN常见问题与继续比较

<a id="yinyun-payment-methods"></a>

### 隐云(YinYun)VPN支持哪些支付方式？

页面列有支付宝、微信支付和 PayPal 等支付方式；选择套餐后会进入安全支付页面完成购买。

<a id="yinyun-cancel-subscription"></a>

### 隐云(YinYun)VPN订阅可以随时取消吗？

可以。机场说明可在账户设置中取消自动续费，取消后仍可使用至当前订阅周期结束。

<a id="yinyun-traffic-exhaustion"></a>

### 隐云(YinYun)VPN通用订阅流量用完后会怎样？

当月流量用完后，服务会自动暂停；可以购买流量包继续使用，或等待下个月流量重置。机场还称会在流量即将用完时提醒用户。专属客户端模式的当前套餐为不限流量，不适用这一规则。

<a id="yinyun-upgrade-or-downgrade-plan"></a>

### 隐云(YinYun)VPN套餐可以升级或降级吗？

可以。机场说明升级可随时进行，差价按比例计算；降级会在下一个计费周期生效。

<a id="yinyun-client-vs-subscription"></a>

### 隐云(YinYun)VPN专属客户端和通用订阅怎么选？

专属客户端适合希望登录后直接使用的人，并提供不限流量档位；通用订阅可导入 Clash、Shadowrocket、sing-box 等兼容客户端，适合自行管理规则和节点的人。

<a id="yinyun-unlimited-traffic-modes"></a>

### 隐云(YinYun)VPN的不限流量适用于哪些模式？

当前表格中的不限流量档位属于专属客户端模式；通用订阅按 150GB、400GB 和 1024GB 分档。不限流量不等于任何时段都具有固定速度，仍应核对公平使用与用途条款。
